# 🎓 02. 원생 및 수업 편성 도메인 (Students & Classes Domain)

## 📌 도메인 개요

원생 & 수업 도메인은 **학원의 기본 자산인 원생(학생 및 학부모) 정보, 수업 반(Class) 개설 및 담당 강사 매핑, 그리고 학생의 반 수강 이력(Enrollment)**을 관리합니다.

---

## 🗄️ 1. 관련 엔티티 (Entities)

### 1) `Student` (원생)
* **역할**: 학원에 등록된 학생 정보 및 학부모 비상 연락처 관리.
* **상태 (`StudentStatus`)**:
  * `ACTIVE`: 재원생 (현재 수업을 듣고 있는 정상 재원생)
  * `ON_LEAVE`: 휴원생 (방학/개인 사정으로 잠시 수업을 쉬는 학생)
  * `DISCHARGED`: 퇴원생 (학원을 퇴원한 학생 - 수납/출결 이력은 영구 보존)
* **주요 필드**:
  * `name`, `gender`, `birthDate`, `schoolName`, `grade` (학년)
  * `studentPhone`: 원생 본인 연락처
  * `parentPhone`: 학부모 연락처 (알림톡/문자 수신처 - 필수)
  * `parentName`, `parentRelationship`: 보호자 성함 및 관계 (모, 부 등)
  * `enrolledAt`, `dischargedAt`: 등록일 및 퇴원일

### 2) `Class` (수업 반)
* **역할**: 과목별, 학년별, 수준별로 개설되는 강의 단위.
* **상태 (`ClassStatus`)**:
  * `ACTIVE`: 정상 운영 중
  * `INACTIVE`: 방학/특강 종료 등으로 인한 임시 휴강
  * `CLOSED`: 완전히 종료된 폐강
* **주요 필드**:
  * `name`: 반 이름 (예: "중등 수학 심화A반", "고등 영어 독해 주말반")
  * `subject`: 과목 (수학, 영어, 국어, 과학 등)
  * `targetGrade`: 대상 학년 (중2, 고1 등)
  * `teacherId`: 담당 강사 User ID (FK)
  * `schedule`: 주간 시간표 (예: "월/수/금 17:00-19:00")
  * `capacity`: 정원 (최대 수강 가능 인원)
  * `monthlyFee`: 월 수강료 (기본 청구 기준 금액)

### 3) `Enrollment` (수강 이력 매핑)
* **역할**: 학생과 수업 반을 기간별로 연결하는 M:N 매핑 엔티티.
* **상태 (`EnrollmentStatus`)**:
  * `ENROLLED`: 현재 수강 중 (출결 및 청구서 생성 대상)
  * `COMPLETED`: 정규 과정 수강 완료 (종강)
  * `DROPPED`: 반 변경 또는 중도 하차
  * `PAUSED`: 수강 일시 정지

## 🔄 3. 원생 등록 및 반 배정 라이프사이클

```text
[ 1. 원생 신규 등록 ]
       │  (Student: ACTIVE)
       ▼
[ 2. 수업 반 배정 (Enrollment 생성) ]
       │  (Enrollment: ENROLLED)
       ├─────────────────────────────────┐
       ▼                                 ▼
[ 3. 매일 1초 출결 체크 대상 ]    [ 4. 매월 수강료 청구서 자동 생성 ]
       │                                 │
       ▼                                 ▼
[ (퇴반/휴원 시) Enrollment: DROPPED / Student: ON_LEAVE ]
```
